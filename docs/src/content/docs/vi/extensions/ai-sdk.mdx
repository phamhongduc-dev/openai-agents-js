Mặc định Agents SDK hoạt động với model OpenAI qua Responses API hoặc Chat Completions API. Tuy nhiên, nếu bạn muốn dùng model khác, [Vercel AI SDK](https://sdk.vercel.ai/) cung cấp nhiều model được hỗ trợ có thể đưa vào Agents SDK qua adapter này.

## Thiết lập

<Steps>

1. Cài đặt AI SDK adapter bằng cách cài extensions package:

   ```bash
   npm install @openai/agents-extensions
   ```

2. Chọn model package mong muốn từ [Vercel's AI SDK](https://ai-sdk.dev/docs/foundations/providers-and-models) và cài đặt:

   ```bash
   npm install @ai-sdk/openai
   ```

3. Import adapter và model để kết nối với agent:

4. Khởi tạo instance model để agent sử dụng:

   <Code lang="typescript" code={aiSdkModelExample} title="Tạo model" />

</Steps>

## Retry

`modelSettings.retry` hoạt động với model dựa trên AI SDK, vì retry được implement bởi Agents runtime.

## Chọn đúng integration

Có hai integration liên quan trong `@openai/agents-extensions`:

- `@openai/agents-extensions/ai-sdk` adapt model AI SDK để `Agent` chạy trên đó.
- `@openai/agents-extensions/ai-sdk-ui` adapt streamed Agents SDK run để AI SDK UI route trả về streaming `Response` chuẩn.

### Lưu ý cho model AI SDK

- Adapter `@openai/agents-extensions/ai-sdk` vẫn ở beta.
- Nếu dùng model OpenAI, ưu tiên default OpenAI model provider.
- Provider AI SDK phải expose `specificationVersion` `v2` hoặc `v3`.
