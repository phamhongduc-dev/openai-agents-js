[**Model Context Protocol (MCP)**](https://modelcontextprotocol.io) là giao thức mở chuẩn hóa cách ứng dụng cung cấp tool và context cho LLM. Hãy nghĩ MCP như cổng USB-C cho ứng dụng AI.

SDK hỗ trợ ba loại MCP server:

1. **Hosted MCP server tool** – MCP server remote dùng như tool bởi OpenAI Responses API
2. **Streamable HTTP MCP server** – server local hoặc remote implement Streamable HTTP transport
3. **Stdio MCP server** – server truy cập qua standard input/output

| Bạn cần gì | Tùy chọn khuyến nghị |
| --- | --- |
| Gọi remote server công khai với model OpenAI responses mặc định | **1. Hosted MCP tool** |
| Dùng remote server với tool call kích hoạt local | **2. Streamable HTTP** |
| Dùng server local chỉ hỗ trợ giao thức standard-I/O | **3. Stdio** |
