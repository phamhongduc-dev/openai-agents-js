Mọi Agent cuối cùng đều gọi LLM. SDK trừu tượng model qua hai interface nhẹ:

- [`Model`](/openai-agents-js/openai/agents/interfaces/model) – biết cách thực hiện _một_ request tới API cụ thể.
- [`ModelProvider`](/openai-agents-js/openai/agents/interfaces/modelprovider) – resolve **tên** model dễ đọc (ví dụ `'gpt‑5.4'`) thành instance `Model`.

## Chọn model

### Model mặc định

Khi không chỉ định model cho `Agent`, model mặc định sẽ được dùng. Mặc định hiện tại là [`gpt-4.1`](https://developers.openai.com/api/docs/models/gpt-4.1).

Có hai cách cấu hình model khác:

1. Thiết lập biến môi trường `OPENAI_DEFAULT_MODEL`:


### ModelSettings

`ModelSettings` phản ánh tham số OpenAI nhưng không phụ thuộc provider.

| Field | Kiểu | Ghi chú |
| --- | --- | --- |
| `temperature` | `number` | Sáng tạo vs. xác định. |
| `topP` | `number` | Nucleus sampling. |
| `toolChoice` | `'auto' \| 'required' \| 'none' \| string` | Xem [ép dùng tool](/openai-agents-js/vi/guides/agents#forcing-tool-use). |
| `maxTokens` | `number` | Token tối đa trong response. |
| `reasoning.effort` | `string` | Mức nỗ lực suy luận cho model gpt-5.x. |
| `providerData` | `Record<string, any>` | Tùy chọn passthrough dành riêng cho provider. |
| `retry` | `ModelRetrySettings` | Cấu hình retry opt-in cho runtime. |
