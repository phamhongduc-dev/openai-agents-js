Agents SDK có thể cung cấp output từ model và các bước thực thi khác một cách tăng dần. Streaming giữ UI responsive và tránh phải đợi toàn bộ kết quả cuối trước khi cập nhật cho người dùng.

## Bật streaming

Truyền tùy chọn `{ stream: true }` vào `Runner.run()` để nhận object streaming thay vì kết quả đầy đủ:

<Code lang="typescript" code={basicStreamingExample} title="Bật streaming" />

Khi streaming được bật, `stream` trả về implement interface `AsyncIterable`. Mỗi event yield mô tả điều gì đã xảy ra trong lần chạy.

### Lấy text output

Gọi `stream.toTextStream()` để nhận stream text được emit. Khi `compatibleWithNodeStreams` là `true`, giá trị trả về là Node.js `Readable` thông thường.

`name` xác định loại item:

| `name`                    | Ý nghĩa                           |
| ------------------------- | --------------------------------- |
| `message_output_created`  | Item message output đã tạo.       |
| `handoff_requested`       | Model yêu cầu handoff.            |
| `handoff_occurred`        | Runtime hoàn thành handoff.       |
| `tool_called`             | Item tool call đã emit.           |
| `tool_output`             | Item kết quả tool đã emit.        |
| `tool_approval_requested` | Tool call tạm dừng chờ phê duyệt. |

## Mẹo

- Nhớ đợi `stream.completed` trước khi thoát.
- Tùy chọn `{ stream: true }` chỉ áp dụng cho lần gọi cung cấp nó.
- Nếu ứng dụng chỉ cần kết quả text, dùng `toTextStream()`.
