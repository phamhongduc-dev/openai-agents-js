Khi bạn [chạy agent](/vi/guides/running-agents), bạn sẽ nhận:

- [`RunResult`](/openai-agents-js/openai/agents/classes/runresult) nếu gọi `run` không có `stream: true`
- [`StreamedRunResult`](/openai-agents-js/openai/agents/classes/streamedrunresult) nếu gọi `run` với `stream: true`

## Chọn đúng bề mặt kết quả

| Nếu bạn cần... | Dùng |
| --- | --- |
| Câu trả lời cuối cùng hiển thị cho người dùng | `finalOutput` |
| Input replay-ready cho lượt tiếp theo | `history` |
| Chỉ các item model-shaped mới từ lần chạy này | `output` |
| Run item phong phú với metadata agent/tool/handoff | `newItems` |
| Agent nên xử lý lượt user tiếp theo | `lastAgent` hoặc `activeAgent` |
| Nối chuỗi Responses API với `previousResponseId` | `lastResponseId` |
| Phê duyệt pending và snapshot có thể resume | `interruptions` và `state` |

## Final output

Property `finalOutput` chứa output cuối cùng của agent cuối cùng chạy:

- `string` — mặc định cho agent không có `outputType`
- `unknown` — nếu agent có JSON schema output type
- `z.infer<outputType>` — nếu agent có Zod schema output type
- `undefined` — nếu agent chưa tạo output

## Các bề mặt input và output

| Property | Chứa gì | Tốt nhất cho |
| --- | --- | --- |
| `input` | Base input cho lần chạy này | Kiểm toán input thực tế |
| `output` | Chỉ item model-shaped mới | Lưu trữ hoặc replay delta mới |
| `newItems` | [`RunItem`](/openai-agents-js/openai/agents/type-aliases/runitem) với metadata phong phú | Log, UI, debug |
| `history` | Input replay-ready từ `input + newItems` | Chat loop thủ công |

## Interruption và trạng thái có thể resume

Nếu tool cần phê duyệt, lần chạy tạm dừng và `interruptions` chứa các [`RunToolApprovalItem`](/openai-agents-js/openai/agents/classes/runtoolapprovalitem) pending.

Resolve phê duyệt qua `result.state.approve(...)` / `result.state.reject(...)`, rồi truyền cùng `state` lại vào `run()` để resume.
