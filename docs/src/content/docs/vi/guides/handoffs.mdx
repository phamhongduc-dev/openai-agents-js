Handoff cho phép agent ủy quyền một phần cuộc hội thoại cho agent khác. Điều này hữu ích khi các agent khác nhau chuyên về các lĩnh vực cụ thể. Ví dụ trong ứng dụng hỗ trợ khách hàng, bạn có thể có agent xử lý đặt chỗ, hoàn tiền hoặc FAQ.

Handoff được biểu diễn như tool cho LLM. Nếu bạn handoff tới agent tên `Refund Agent`, tên tool sẽ là `transfer_to_refund_agent`.

> Đọc trang này sau [Agent](/openai-agents-js/vi/guides/agents#composition-patterns) khi bạn biết agent chuyên biệt nên tiếp quản cuộc hội thoại. Nếu agent chuyên biệt nên ở phía sau agent gốc, dùng [agent dùng như tool](/openai-agents-js/vi/guides/tools#4-agents-as-tools) thay thế.

## Tạo handoff

Mọi agent đều chấp nhận tùy chọn `handoffs`. Nó có thể chứa instance `Agent` khác hoặc object `Handoff` được trả về bởi helper `handoff()`.

### Tùy chỉnh handoff qua `handoff()`

Hàm `handoff()` cho phép tinh chỉnh tool được sinh ra.

- `agent` – agent để handoff tới.
- `toolNameOverride` – ghi đè tên tool mặc định `transfer_to_<agent_name>`.
- `toolDescriptionOverride` – ghi đè mô tả tool mặc định.
- `onHandoff` – callback khi handoff xảy ra.
- `inputType` – schema cho tham số tool-call handoff.
- `inputFilter` – lọc history truyền cho agent tiếp theo.
- `isEnabled` – boolean hoặc predicate để chỉ expose handoff cho các lần chạy phù hợp.
