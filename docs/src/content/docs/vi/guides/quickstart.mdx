## Thiết lập Project

<Steps>

1. Tạo project và khởi tạo npm. Bạn chỉ cần làm bước này một lần.

   ```bash
   mkdir my_project
   cd my_project
   npm init -y
   ```

2. Cài đặt Agents SDK và Zod. SDK sử dụng Zod v4 cho tool schema và structured output.

   ```bash
   npm install @openai/agents zod
   ```

3. Thiết lập OpenAI API key. Nếu bạn chưa có, hãy theo [hướng dẫn này](https://platform.openai.com/docs/quickstart#create-and-export-an-api-key) để tạo OpenAI API key.

   ```bash
   export OPENAI_API_KEY=sk-...
   ```

   Ngoài ra bạn có thể gọi `setDefaultOpenAIKey('<api key>')` để thiết lập key bằng code và dùng `setTracingExportApiKey('<api key>')` cho tracing. Xem [hướng dẫn cấu hình](/vi/guides/config) để biết thêm chi tiết.

</Steps>

## Xem trace

Agents SDK sẽ tự động sinh trace cho bạn. Điều này cho phép bạn xem lại cách agent hoạt động, tool nào chúng đã gọi hoặc agent nào chúng đã handoff tới.

Để xem lại những gì đã xảy ra trong lần chạy agent, truy cập [Trace viewer trên OpenAI Dashboard](https://platform.openai.com/traces).
