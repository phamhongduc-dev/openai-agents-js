Session cung cấp cho Agents SDK **lớp bộ nhớ lâu dài**. Cung cấp bất kỳ object nào implement interface `Session` cho `Runner.run`, và SDK xử lý phần còn lại. Khi session có mặt, runner tự động:

1. Lấy item hội thoại đã lưu và prepend chúng vào lượt tiếp theo.
2. Duy trì user input và assistant output mới sau mỗi lần chạy.
3. Giữ session sẵn sàng cho các lượt tương lai.

SDK đi kèm hai implementation: `OpenAIConversationsSession` cho Conversations API và `MemorySession` cho phát triển local.

## Hành vi session cốt lõi

### Cách runner dùng session

- **Trước mỗi lần chạy** lấy session history, merge với input lượt mới.
- **Sau lần chạy không streaming** một lần gọi `session.addItems()` duy trì cả user input và model output.
- **Cho lần chạy streaming** ghi user input trước và thêm output streaming khi lượt hoàn tất.
- **Khi resume từ `RunResult.state`** tiếp tục truyền cùng `session`.
