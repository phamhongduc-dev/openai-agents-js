Trang này đề cập **các giá trị mặc định toàn SDK** mà bạn thường thiết lập một lần khi khởi động ứng dụng, như OpenAI client mặc định, transport, tracing export key, và hành vi debug logging. Các thiết lập này áp dụng cho toàn bộ process theo mặc định, nên đây là nơi phù hợp cho cấu hình chung thay vì tinh chỉnh cho từng agent hoặc từng lần chạy.

Nếu bạn cần cấu hình cho một `Agent`, `Runner`, hoặc lệnh gọi `run()` cụ thể, hãy xem:

- [Chạy Agent](/openai-agents-js/vi/guides/running-agents) cho `Runner` và các tùy chọn theo lần chạy.
- [Model](/openai-agents-js/vi/guides/models) cho cài đặt model ở cấp agent và runner.
- [Tracing](/openai-agents-js/vi/guides/tracing) cho cấu hình tracing theo lần chạy và hành vi exporter.

### Responses transport

Nếu bạn đang dùng Responses API, bạn cũng có thể chọn transport của OpenAI provider. Mặc định là HTTP.

<Code
  lang="typescript"
  code={setOpenAIResponsesTransportExample}
  title="Thiết lập Responses transport"
/>

Dùng `setOpenAIResponsesTransport('websocket')` để bật WebSocket transport và `setOpenAIResponsesTransport('http')` để chuyển lại. Nếu bạn định tuyến websocket traffic qua proxy hoặc gateway, hãy thiết lập `OPENAI_WEBSOCKET_BASE_URL` (hoặc cấu hình `websocketBaseURL` trên `OpenAIProvider` của bạn).

Giá trị mặc định toàn process này chỉ ảnh hưởng đến các model được resolve qua OpenAI provider mặc định sau đó. Nếu bạn truyền instance `Model` cụ thể hoặc `modelProvider` tùy chỉnh, hãy cấu hình transport ở đó. Xem [hướng dẫn Model](/openai-agents-js/vi/guides/models#responses-websocket-transport).

### Debug logging

SDK sử dụng package [`debug`](https://www.npmjs.com/package/debug) cho debug logging. Thiết lập biến môi trường `DEBUG` thành `openai-agents*` để xem log chi tiết.

```bash
export DEBUG=openai-agents*
```

Để log hoạt động lưu session, thiết lập `OPENAI_AGENTS__DEBUG_SAVE_SESSION=1`.

Bạn có thể lấy namespaced logger cho module riêng bằng `getLogger(namespace)` từ `@openai/agents`.

#### Dữ liệu nhạy cảm trong log

Một số log có thể chứa dữ liệu người dùng. Hãy tắt chúng bằng các biến môi trường sau.

Để tắt logging input và output của LLM:

```bash
export OPENAI_AGENTS_DONT_LOG_MODEL_DATA=1
```

Để tắt logging input và output của tool:

```bash
export OPENAI_AGENTS_DONT_LOG_TOOL_DATA=1
```
