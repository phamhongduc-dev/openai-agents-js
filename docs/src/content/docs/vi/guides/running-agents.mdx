## Lifecycle và cấu hình Runner

### Agent loop

Khi dùng method run của Runner, bạn truyền agent khởi đầu và input. Runner chạy vòng lặp:

1. Gọi model của agent hiện tại với input hiện tại.
2. Kiểm tra response LLM:
   - **Final output** → trả về.
   - **Handoff** → chuyển sang agent mới, giữ history, quay lại 1.
   - **Tool call** → thực thi tool, thêm kết quả vào hội thoại, quay lại 1.
3. Throw [`MaxTurnsExceededError`](/openai-agents-js/openai/agents-core/classes/maxturnsexceedederror) khi đạt `maxTurns`.

### Tham số run

| Tùy chọn | Mặc định | Mô tả |
| --- | --- | --- |
| `stream` | `false` | Nếu `true` trả về `StreamedRunResult` và emit event khi nhận. |
| `context` | – | Object context chuyển tiếp tới mọi tool/guardrail/handoff. |
| `maxTurns` | `10` | Giới hạn an toàn. |
| `signal` | – | `AbortSignal` cho hủy bỏ. |
| `session` | – | Implementation session persistence. Xem [hướng dẫn Session](/openai-agents-js/vi/guides/sessions). |
| `conversationId` | – | Tái sử dụng hội thoại server-side (Responses API + Conversations API). |
| `previousResponseId` | – | Tiếp tục từ Responses API call trước. |

## Quản lý trạng thái và hội thoại

### Chọn chiến lược memory

| Chiến lược | Trạng thái ở đâu | Tốt nhất cho | Truyền gì lượt tiếp theo |
| --- | --- | --- | --- |
| `result.history` | Memory ứng dụng | Chat loop nhỏ, kiểm soát thủ công hoàn toàn | `result.history` |
| `session` | Storage của bạn + SDK | Chat state lâu dài, lần chạy có thể resume | Cùng instance `session` |
| `conversationId` | OpenAI Conversations API | Trạng thái server-side chia sẻ | Cùng `conversationId` + chỉ lượt user mới |
| `previousResponseId` | OpenAI Responses API | Continuation đơn giản nhất | `result.lastResponseId` + chỉ lượt user mới |

## Lỗi và phục hồi

### Exception

SDK throw một tập nhỏ lỗi:

- [`MaxTurnsExceededError`](/openai-agents-js/openai/agents-core/classes/maxturnsexceedederror) – đạt `maxTurns`.
- [`ModelBehaviorError`](/openai-agents-js/openai/agents-core/classes/modelbehaviorerror) – model sinh output không hợp lệ.
- [`InputGuardrailTripwireTriggered`](/openai-agents-js/openai/agents-core/classes/inputguardrailtripwiretriggered) / [`OutputGuardrailTripwireTriggered`](/openai-agents-js/openai/agents-core/classes/outputguardrailtripwiretriggered) – vi phạm guardrail.
- [`UserError`](/openai-agents-js/openai/agents-core/classes/usererror) – lỗi từ cấu hình hoặc input người dùng.
