<Aside type="caution">

Chọn kiến trúc sớm:

- `OpenAIRealtimeWebRTC` là đường dễ nhất cho browser, xử lý audio input/output cho bạn.
- `OpenAIRealtimeWebSocket` cho nhiều control hơn, nhưng bạn phải tự quản lý audio.
- Function tool chạy ở nơi `RealtimeSession` chạy. Nếu session trong browser, tool cũng chạy trong browser.
- Realtime handoff giữ cùng live session model. Voice change chỉ hoạt động trước khi session tạo audio output.

</Aside>
