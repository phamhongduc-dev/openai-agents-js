Chọn transport dựa trên nơi session chạy và mức độ control bạn cần cho raw media hoặc event.

| Tình huống | Transport khuyến nghị | Lý do |
| --- | --- | --- |
| Ứng dụng speech-to-speech trên browser | `OpenAIRealtimeWebRTC` | Đường dễ nhất. SDK quản lý capture mic, playback, và kết nối WebRTC. |
| Voice loop server-side hoặc audio pipeline tùy chỉnh | `OpenAIRealtimeWebSocket` | Tốt khi bạn đã control audio capture/playback và muốn truy cập event trực tiếp. |
| SIP hoặc telephony bridge | `OpenAIRealtimeSIP` | Gắn `RealtimeSession` vào cuộc gọi SIP-initiated có sẵn. |
| Cloudflare Workers / workerd | Cloudflare extension transport | workerd không thể mở WebSocket đi ra bằng constructor `WebSocket` toàn cục. |
| Luồng điện thoại trên Twilio | Twilio extension transport | Xử lý audio forwarding và interruption behavior cho Twilio. |
