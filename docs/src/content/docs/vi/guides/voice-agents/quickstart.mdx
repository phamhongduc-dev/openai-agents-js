## Thiết lập project và thông tin xác thực

<Steps>

1. **Tạo project**

   Trong quickstart này chúng ta sẽ tạo voice agent dùng được trong browser. Bạn có thể bắt đầu với [`Next.js`](https://nextjs.org/docs/getting-started/installation) hoặc [`Vite`](https://vite.dev/guide/installation.html).

   ```bash
   npm create vite@latest my-project -- --template vanilla-ts
   ```

2. **Cài đặt package khuyến nghị** (yêu cầu Zod v4)

   ```bash
   npm install @openai/agents zod
   ```

3. **Tạo client ephemeral token**

   Vì ứng dụng chạy trong browser người dùng, chúng ta cần cách an toàn để kết nối model qua Realtime API. Backend tạo ephemeral token ngắn hạn, browser dùng token đó để thiết lập kết nối WebRTC.

   ```bash
   export OPENAI_API_KEY="sk-proj-...(key của bạn)"
   curl -X POST https://api.openai.com/v1/realtime/client_secrets \
      -H "Authorization: Bearer $OPENAI_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "session": {
          "type": "realtime",
          "model": "gpt-realtime"
        }
      }'
   ```

</Steps>

<Aside type="note">
  Luồng browser production: browser hỏi backend lấy ephemeral token mới, backend
  gọi `POST /v1/realtime/client_secrets` với server API key, browser truyền
  token `ek_...` trả về vào `session.connect(...)`.
</Aside>

## Tạo và kết nối voice agent

<Steps>

1. **Tạo Agent đầu tiên**

   Tạo [`RealtimeAgent`](/openai-agents-js/openai/agents-realtime/classes/realtimeagent/) rất tương tự tạo [`Agent`](/vi/guides/agents) thông thường.

   ```typescript
   import { RealtimeAgent } from '@openai/agents/realtime';

   const agent = new RealtimeAgent({
     name: 'Assistant',
     instructions: 'You are a helpful assistant.',
   });
   ```

2. **Tạo session**

   Không giống agent thông thường, voice agent chạy liên tục bên trong `RealtimeSession` xử lý hội thoại và kết nối tới model.

   ```typescript
   import { RealtimeSession } from '@openai/agents/realtime';

   const session = new RealtimeSession(agent, {
     model: 'gpt-realtime-1.5',
   });
   ```

3. **Kết nối session**

   ```typescript
   await session.connect({ apiKey: 'ek_...(token của bạn)' });
   ```

</Steps>
